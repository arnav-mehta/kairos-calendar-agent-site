# Kairos Calendar Agent

This repository hosts the public beta information page for Kairos Calendar Agent.

Kairos is an invite-only scheduling assistant that helps users find availability across selected Google and Microsoft calendars, review scheduling emails, and prepare replies or calendar invites.

## Public Page

When GitHub Pages is enabled, the site will be available at:

https://arnav-mehta.github.io/kairos-calendar-agent-site/

## Updating This Site

The page is copied from the private Kairos app repository's public documentation page:

`calendar-agent/docs/index.html`

When Kairos functionality changes, update the documentation there first, then copy the public page and assets into this repository.

## Files

- `index.html`: public beta overview, setup instructions, and functionality summary.
- `assets/kairos_logo.png`: Kairos logo used on the page.
